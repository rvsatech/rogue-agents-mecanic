# rogue-agents-mecanic

Protótipo em Unity de movimentação de shooter em 3ª pessoa (PC), inspirado no Rogue Agents:
pulo com bhop, air strafe, slide, rolamento, wall-run, escalada, barreira instantânea e tiro em movimento.

Especificação completa das mecânicas: [CLAUDE.md](CLAUDE.md).

**Engine:** Unity 6.6 (6000.6.10f1)
